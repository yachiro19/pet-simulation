# PET Simulation

Учебная Монте-Карло симуляция ПЭТ на [Geant4](https://geant4.web.cern.ch/) с полной оптической физикой и Python-скриптами для анализа результатов. Программа работает в двух режимах:

| Режим | Запуск | Что моделирует |
|---|---|---|
| `ring` (по умолчанию) | `PET_simulation.exe [макрос]` | кольцевой ПЭТ-сканер из 24 кристаллов LYSO |
| `tof` | `PET_simulation.exe -m tof [макрос]` | два детекторных модуля 2×2 для изучения временного разрешения (CTR) TOF-ПЭТ с черенковской временной отметкой — см. [раздел ниже](#режим-tof-ctr-и-черенковская-временная-отметка) |

## Режим ring: что моделируется

- **Детектор**: кольцо из 24 кристаллов LYSO 10×10×30 мм (радиус кольца 150 мм, длинная ось ориентирована радиально). Каждый кристалл обёрнут отражателем (ESR, отражательная способность 98 %).
- **Фотодетекторы**: SiPM 10×10×1 мм на наружном торце каждого кристалла, квантовая эффективность около 40 %.
- **Источник**: позитроны с энергией 250–500 кэВ, испускаются изотропно из водного куба 50 мм в центре кольца. Позитрон аннигилирует, и пара гамма-квантов по 511 кэВ регистрируется кристаллами.
- **Физика**: `G4EmStandardPhysics`, радиоактивный распад, адронная физика FTFP_BERT, оптическая физика (сцинтилляция LYSO со световыходом 320 фотонов/МэВ, время высвечивания 40 нс, черенковское излучение).

Каждое событие с ненулевым энерговыделением записывается в `pet_data.csv`:

| Колонка | Описание |
|---|---|
| `EventID` | номер события |
| `TotalEnergy_keV` | суммарное энерговыделение в кристаллах |
| `NumGammaHits` | число шагов с энерговыделением (без оптических фотонов) |
| `CrystalIDs` | номера кристаллов для каждого хита, через `;` |
| `Energies_keV` | энергия каждого хита, через `;` |
| `Times_ns` | глобальное время каждого хита, через `;` |
| `PhotonCount` | число оптических фотонов, дошедших до SiPM |
| `PhotonEnergy_eV` | суммарная энергия этих фотонов |

## Требования

| | Версия |
|---|---|
| Geant4 | **11.3.0** (подойдёт любая 11.x). Нужна сборка с наборами данных (`GEANT4_INSTALL_DATA=ON`), а для визуализации — с OpenGL (`GEANT4_USE_OPENGL_WIN32=ON` на Windows, `GEANT4_USE_QT=ON` или `GEANT4_USE_OPENGL_X11=ON` на Linux) |
| CMake | ≥ 3.16 |
| Компилятор с C++17 | Windows: Visual Studio 2022 (MSVC); Linux: GCC ≥ 9 или Clang ≥ 10 |
| Python | ≥ 3.9 с пакетами из `requirements.txt` (pandas, numpy, matplotlib) |

## Сборка и запуск

Программа ищет макросы и пишет `pet_data.csv` **в текущей папке**, поэтому запускайте её из папки, где лежит исполняемый файл. Макросы копируются туда автоматически при сборке.

### Windows (Visual Studio 2022)

`CMakeLists.txt` по умолчанию ищет Geant4 в `C:/Geant4/geant4-v11.3.0-inst`. Если Geant4 установлен в другое место, передайте путь через `-DGeant4_DIR=...`. Папка `bin` установки Geant4 должна быть в `PATH`, чтобы находились DLL.

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
# или с другим путём к Geant4:
# cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DGeant4_DIR="D:/geant4-inst/lib/cmake/Geant4"
cmake --build build --config Release

cd build\Release
.\PET_simulation.exe batch.mac     # пакетный режим -> pet_data.csv
.\PET_simulation.exe               # интерактивный режим с визуализацией (выполняет run.mac)
```

### Linux

```bash
source /path/to/geant4-install/bin/geant4.sh   # переменные окружения Geant4

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
# если Geant4 не находится автоматически:
# cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DGeant4_DIR=/path/to/geant4-install/lib/cmake/Geant4
cmake --build build -j

cd build
./PET_simulation batch.mac         # пакетный режим -> pet_data.csv
./PET_simulation                   # интерактивный режим с визуализацией
```

Число событий меняется в макросе командой `/run/beamOn N`. Оптическая физика заметно замедляет расчёт, поэтому для проверки удобнее начинать с `test.mac`.

## Режим tof: CTR и черенковская временная отметка

Цель: исследовать временное разрешение совпадений (CTR) TOF-ПЭТ с временной отметкой по черенковскому излучению, сравнить материалы и формы кристаллов и выяснить, можно ли различить смещение источника на 1 мм вдоль линии отклика. Это смещение меняет разность времён прилёта квантов на 2·1 мм / c ≈ 6.67 пс.

### Установка

- **Модули.** Два модуля на оси z друг напротив друга: модуль 0 при z < 0 (время t1), модуль 1 при z > 0 (время t2).
  - Модуль — матрица 2×2 кристаллов. У каждого кристалла своя обёртка (`esr`, `teflon`, `black`, `none`) и свой SiPM на внешнем торце.
  - SiPM — оптическое окно с n = 1.5. Зарегистрированный фотон проходит отбор по PDE(λ) (кривая NUV-SiPM) и получает гауссов разброс времени SPTR.
- **Форма кристалла.** `box` (параллелепипед) или `trd` (усечённая пирамида G4Trd), у которой узкий торец может быть со стороны SiPM или со стороны источника. Новые формы добавляются одним классом, см. `include/tof/CrystalShape.hh`.
- **Материалы.** LYSO:Ce, BGO, PbF₂ (только Черенков). Показатель преломления, поглощение, спектр и времена сцинтилляции — функции энергии фотона. Источники значений указаны в `src/tof/TofMaterials.cc`.
- **Источник.** Водный куб 1 мм³ на оси, положение задаётся из макроса.
  - `gammaPair` (по умолчанию): пары квантов 511 кэВ в противоположных направлениях, разыгранные в конусе на модули.
  - `positron`: позитрон, аннигиляция по Geant4.
- **Физика.** `G4EmStandardPhysics_option4` + `G4OpticalPhysics`: сцинтилляция с конечным временем нарастания и `G4Cerenkov`.

### Параметры (команды макроса, без перекомпиляции)

Все команды с комментариями и значениями по умолчанию собраны в [`macros/tof/config_default.mac`](macros/tof/config_default.mac).

| Группа | Команды |
|---|---|
| `/tof/det/` | `material`, `shape`, `taper`, `narrowEnd`, `moduleSize`, `gap`, `length`, `distance`, `wrapping`, `reflectivity`, `windowIndex` |
| `/tof/source/` | `z`, `x`, `y`, `size` |
| `/tof/gun/` | `type`, `coneAngle`, `positronEnergy` |
| `/tof/sipm/` | `pdeModel`, `pdeScale`, `pde`, `sptr` |
| `/tof/opt/` | `timeCut` — оптические фотоны, рождённые позже, не отслеживаются (по умолчанию 5 нс) |
| `/tof/output/` | `dir`, `tag`, `nFirst`, `autoSeed` |

По умолчанию: кристаллы 3×3×20 мм (торец модуля 6.1 мм, зазор 0.1 мм), модули в 100 мм друг от друга, обёртка ESR (R = 0.98), SPTR 70 пс FWHM.

### Макросы (`macros/tof/`)

| Макрос | Что делает |
|---|---|
| `vis.mac` | визуализация установки (запуск `-m tof` без макроса) |
| `test.mac` | быстрая проверка: 20 событий |
| `config_default.mac` | все параметры и число событий на точку (`/control/alias nev 20000`) |
| `scan.mac` | скан положения источника −3…+3 мм с шагом 1 мм для одной конфигурации |
| `compare.mac` | все материалы × формы × положения в одном процессе |
| `point.mac`, `scan_positions.mac`, `compare_*.mac` | вспомогательные, вызываются из перечисленных выше |

Запуск — из папки с программой (`build\Release` на Windows, `build` на Linux):

```powershell
.\PET_simulation.exe -m tof tof/test.mac      # проверка
.\PET_simulation.exe -m tof tof/scan.mac      # скан для конфигурации по умолчанию (LYSO, box)
.\PET_simulation.exe -m tof                   # визуализация
```

Быстрее всего полное сравнение считается параллельно: каждая конфигурация запускается отдельным процессом (из корня репозитория).

```bash
python scripts/run_tof_campaign.py                                  # 3 материала x 2 формы, 20000 событий на точку
python scripts/run_tof_campaign.py --materials LYSO --shapes box trd:0.5:source --nev 5000
python scripts/run_tof_campaign.py --extra "/tof/sipm/sptr 30 ps" --out results/tof_sptr30
```

### Сколько это считается

Оптические фотоны — самая дорогая часть. Время на одно событие (Intel Core i5-12450H, 12 потоков, Windows 11, сборка Release, отсечка фотонов 5 нс по умолчанию):

| Материал | мс/событие | Точка (20 000 событий) | Скан 7 точек |
|---|---|---|---|
| LYSO, брусок | ~20 | ~7 мин | ~50 мин |
| LYSO, пирамида | ~40–50 (свет дольше блуждает) | ~15 мин | ~1.5 ч |
| BGO | ~2–4 | ~1 мин | ~5–10 мин |
| PbF₂ | ~0.3 | ~6 с | ~1 мин |

Цифры получены при 6 одновременных процессах; один процесс считается примерно на треть быстрее. Полная серия `run_tof_campaign.py` (3 материала × 2 формы × 7 положений, 20 000 событий на точку) займёт около 1.5 часов; её длительность определяет LYSO с пирамидой. Без отсечки (`/tof/opt/timeCut 0`) LYSO считается примерно в 8 раз дольше: в первые 5 нс высвечивается лишь 12 % света.

20 000 событий дают около 1 500 совпадений «1 кристалл + 1 кристалл» на точку (~8 % событий). Этого достаточно для CTR с точностью ~5 %. Сколько событий нужно, чтобы различить сдвиг 1 мм, анализ пишет сам (столбец N₃σ).

### Выходные данные

Каждый прогон (`/run/beamOn`) пишет `tof_output/tof_<материал>_<форма>_z<положение>mm.csv`. Строка — один кристалл с энерговыделением или фотонами в одном событии:

| Столбцы | Содержание |
|---|---|
| `material … src_z_mm` | параметры конфигурации (повторяются в каждой строке) |
| `module`, `crystal` | модуль (0/1) и кристалл в матрице (0–3) |
| `edep_keV` | энерговыделение |
| `t_gamma_ps`, `doi_mm` | время и глубина первого взаимодействия гамма-кванта (MC-правда) |
| `n_scint`, `n_cher` | число зарегистрированных фотонов от сцинтилляции и от Черенкова |
| `t_first_ps`, `t_first_scint_ps`, `t_first_cher_ps` | время первого фотона: любого, сцинтилляционного, черенковского |
| `t01_ps … t10_ps`, `types` | времена первых N фотонов и их происхождение (`S`/`C`) |

`n_scint` считает только фотоны, рождённые до `timeCut`. Для энергии используйте `edep_keV`.

### Анализ

```bash
python analysis/tof/tof_analysis.py results/tof                 # каталог с tof_*.csv
python analysis/tof/tof_analysis.py results/tof --ewin 425 650  # фотопиковое окно, кэВ
```

- **Отбор совпадений.** Ровно один сработавший кристалл (энерговыделение ≥ 10 кэВ) в каждом модуле. Результаты считаются для всех таких совпадений и отдельно для фотопика.
- **Временная отметка кристалла.** Первый фотон, среднее первых трёх, первый черенковский, первый сцинтилляционный.
- **Что вычисляется для Δt = t1 − t2:**
  - **CTR (FWHM)** — по ядерной оценке плотности, без предположения о гауссовой форме (у BGO и PbF₂ длинные хвосты);
  - **центр пика** — среднее в окне ±FWHM;
  - **ошибки** — бутстрэпом;
  - **наклон** центра пика от положения источника (ожидается 6.67 пс/мм);
  - **d′** — разделение соседних положений в единицах σ одного события;
  - **N₃σ** — сколько событий нужно на положение, чтобы различить 1 мм по средним.
- **Результаты** (в `<каталог>/analysis/`):
  - `summary.md` — сводные таблицы материал × форма × положение;
  - `by_config.csv`, `by_position.csv`;
  - графики `dt_by_position.png`, `mean_vs_z.png`, `ctr_comparison.png`, `cherenkov.png`.
