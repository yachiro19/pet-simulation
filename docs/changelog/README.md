# Журнал изменений

Каждое изменение проекта описывается отдельным файлом `NNN-краткое-название.md`. Файл коммитится вместе с кодом, к которому относится, поэтому история разработки диплома восстанавливается и по коду, и по описаниям.

Найти коммит, к которому относится описание:

```bash
git log --follow -- docs/changelog/002-*.md
```

## Шаблон

```markdown
# NNN. Название изменения

**Дата:** ГГГГ-ММ-ДД

## Что сделано
Кратко, по пунктам.

## Зачем
Мотивация: какая задача диплома, какая проблема или какой вопрос.

## Как
Изменённые файлы, ключевые решения, формулы, параметры. Почему выбран именно такой вариант.

## Проверка и результат
Как проверено (макрос, число событий, команды). Что получилось: числа, графики, выводы.
```
