# 002. Режим tof: установка, материалы, физика, источник

**Дата:** 2026-10-07

## Что сделано

- Добавлен второй режим работы программы — `tof`, выбирается аргументом `-m tof`. Без аргумента, как и раньше, запускается кольцевой ПЭТ, его код не изменялся.
- Новая установка: два детекторных модуля друг напротив друга на оси z. Каждый модуль — матрица 2×2 кристаллов. У каждого кристалла своя отражающая обёртка и свой SiPM на внешнем торце.
- Форма кристалла — параметр: прямоугольный параллелепипед (`box`) и усечённая пирамида (`trd`, G4Trd). Архитектура расширяемая.
- Три материала с оптическими свойствами как функциями энергии фотона: LYSO:Ce, BGO, PbF₂. PbF₂ задан без сцинтилляции.
- Физика: электромагнитная (`G4EmStandardPhysics_option4`) и оптическая (сцинтилляция с конечным временем нарастания + `G4Cerenkov`).
- Источник: куб 1 мм³ на оси. Пары гамма-квантов 511 кэВ в противоположных направлениях или, опционально, позитрон.
- Все размеры, форма, материал, обёртка и положение источника задаются командами макроса (`G4GenericMessenger`) без перекомпиляции. При изменении параметра геометрия пересобирается перед следующим `/run/beamOn`.

## Зачем

Задача — исследовать временное разрешение совпадений (CTR) TOF-ПЭТ с временной отметкой по черенковскому излучению и подобрать форму детекторов, дающую лучший результат. Конечный вопрос: можно ли различить смещение источника на 1 мм вдоль линии отклика. Смещение на Δz меняет разность времён прилёта квантов на Δt = 2Δz/c ≈ 6.67 пс/мм.

Кольцевая геометрия для этого неудобна. Нужна простая воспроизводимая установка, как в лабораторных измерениях CTR: два детектора на одной оси и источник между ними, у которого можно быстро менять материал и форму кристаллов.

## Как

**Выбор режима** (`src/main.cc`). Аргумент `-m ring|tof`. В Geant4 user actions создаются до выполнения макроса, а у режимов разные детектор, физика и сбор данных, поэтому режим выбирается при запуске, а не командой макроса.

**Новые классы** (`src/tof/`, `include/tof/`):

| Класс | Назначение |
|---|---|
| `TofDetectorConstruction` | Геометрия и команды `/tof/det/*`, `/tof/source/*` |
| `CrystalShape`, `BoxShape`, `TrdShape`, `ShapeRegistry` | Формы кристалла; реестр «имя → форма» |
| `TofMaterials` | Материалы и их оптические таблицы |
| `TofPhysicsList` | Список физических процессов |
| `TofPrimaryGenerator` | Источник, команды `/tof/gun/*` |
| `TofActionInitialization` | Связка user actions режима |

**Геометрия.**
- Модуль 0 при z < 0, модуль 1 при z > 0. Номер кристалла = 4·модуль + номер в матрице. Тот же номер получает SiPM.
- Торец модуля (`moduleSize`, по умолчанию 6.1 мм) делится на 4 кристалла с зазором `gap` (0.1 мм), получаются кристаллы 3×3 мм. Длина `length` — 20 мм, расстояние между торцами модулей `distance` — 100 мм.
- Для `trd` широкий торец равен 3×3 мм, узкий — `taper`×3 мм. Узкий торец можно поставить со стороны SiPM или со стороны источника (`narrowEnd`). Кристаллы в матрице параллельны оси, шаг определяется широким торцом, поэтому кристаллы не пересекаются.
- SiPM моделируется как оптическое окно (n = 1.5, `windowIndex`) размером с торец кристалла. Граница кристалл→окно — полированная `G4LogicalBorderSurface`, на ней работают формулы Френеля, а при n_кристалла > n_окна — и полное внутреннее отражение. Это важно для LYSO, BGO и PbF₂ с n ≈ 1.8–2.2.
- Обёртка — `G4LogicalSkinSurface` на каждый кристалл (модель unified):

  | Тип | Модель |
  |---|---|
  | `esr` | зеркальный отражатель через воздушный зазор (`polishedbackpainted`) |
  | `teflon` | диффузный (`groundbackpainted`) |
  | `black` | поглощающая краска |
  | `none` | голый кристалл |

  Коэффициент отражения — `reflectivity`, по умолчанию 0.98.

**Расширяемость форм.** Новая форма — это класс-наследник `CrystalShape` с методами `Build()` (строит G4VSolid) и `SiPMFaceHalf()` (размер торца под SiPM) и одна строка в `RegisterBuiltinShapes()`. Команда `/tof/det/shape` автоматически получает новое имя в списке допустимых значений.

**Материалы** (`TofMaterials.cc`, источники перечислены в начале файла):

| | LYSO:Ce | BGO | PbF₂ |
|---|---|---|---|
| Плотность, г/см³ | 7.1 | 7.13 | 7.77 |
| n (опорные точки) | 1.82 @ 420 нм; 1.80 @ 600 нм (оценка) | 2.15 @ 480 нм; 2.10 @ 633 нм | 1.82 @ 400 нм; 1.77 @ 589 нм |
| Край пропускания | ~390 нм | ~310 нм | ~255 нм |
| Световыход, фот./МэВ | 32 000 | 8 500 | — |
| Нарастание / спад | 70 пс / 40 нс | 0 / 300 нс | — |
| Пик эмиссии | 420 нм | 480 нм | — |

- n(λ) строится однотермовой формулой Селлмейера n² = 1 + Bλ²/(λ² − C), коэффициенты B и C подбираются по двум опорным точкам. Сетка длин волн — 250–700 нм с шагом 10 нм. Это аппроксимация, а не оцифрованная кривая, что прямо оговорено в комментариях к коду.
- Так как G4Cerenkov генерирует фотоны во всём диапазоне таблицы RINDEX, UV-часть черенковского спектра реально обрезается краем пропускания материала.

**Физика.**
- `G4EmStandardPhysics_option4` — самая точная EM-модель при низких энергиях.
- `G4OpticalPhysics`: сцинтилляция с `SetScintFiniteRiseTime(true)` и черенковское излучение.
- Порог рождения вторичных частиц снижен до 0.1 мм, чтобы дельта-электроны выше черенковского порога (~0.1 МэВ) рождались явно.
- Адронная физика не подключена: для квантов 511 кэВ она не нужна.

**Источник.**
- Точка вылета равномерно разыгрывается в кубе 1 мм³ (`/tof/source/z`, `x`, `y`, `size`).
- Режим `gammaPair` — два кванта по 511 кэВ в противоположных направлениях со взаимно перпендикулярными поляризациями. Направление разыгрывается в конусе, который накрывает модули, причём угол по умолчанию выбирается автоматически. Это выборка по важности: при изотропном источнике в модули 6×6 мм на расстоянии 50 мм попадает ~0.1 % событий. Так как между источником и детекторами нет рассеивающей среды, конус не искажает зарегистрированные события.
- Режим `positron` — изотропный позитрон в водном кубе, аннигиляцию моделирует Geant4.
- Неколлинеарность аннигиляционных квантов не учитывается.

## Проверка и результат

- Сборка Release (MSVC 2022, Geant4 11.3.0) прошла без ошибок и предупреждений.
- Проверка перекрытий Geant4 (`checkOverlaps`): все объёмы `OK` для `box` и `trd` при обоих направлениях сужения.
- В одном запуске по очереди менялись форма, материал, сторона сужения, положение источника и обёртка. Геометрия корректно пересобирается перед каждым `/run/beamOn`.
- Недопустимые значения (`/tof/det/material Glass`) отклоняются командой.
- Сбор выходных данных добавлен в следующем шаге (003).
