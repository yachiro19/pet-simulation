# 003. Режим tof: регистрация фотонов SiPM и выходные данные

**Дата:** 2026-10-07

## Что сделано

- Регистрация оптических фотонов SiPM:
  - спектральная квантовая эффективность (PDE);
  - разброс времени одного фотона (SPTR);
  - разделение фотонов по процессу-создателю: сцинтилляция или Черенков.
- Запись энерговыделения, времени и глубины первого взаимодействия гамма-кванта в каждом кристалле.
- Вывод в CSV: одна строка на сработавший кристалл в событии, отдельный файл на каждый прогон.
- Ускорение счёта: оптические фотоны, рождённые позже `timeCut` (по умолчанию 5 нс), сразу уничтожаются.
- Воспроизводимое зерно генератора случайных чисел для каждой конфигурации.

## Зачем

Для CTR нужны времена прихода первых фотонов на SiPM обоих детекторов. Чтобы оценить вклад черенковского излучения во временную отметку, нужно знать происхождение каждого из первых фотонов. MC-правда (время и глубина взаимодействия гамма-кванта) позволяет отделить вклад самого детектора от разброса точки взаимодействия по глубине кристалла.

## Как

**Новые классы** (`src/tof/`, `include/tof/`):

| Класс | Назначение |
|---|---|
| `TofSettings` | Параметры SiPM, вывода и трекинга: команды `/tof/sipm/*`, `/tof/output/*`, `/tof/opt/*` |
| `TofSteppingAction` | Энерговыделение в кристаллах; регистрация фотонов на входе в SiPM |
| `TofEventAction` | Накопление данных по 8 кристаллам за событие |
| `TofRunAction` | Открытие CSV на прогон, запись строк, замер времени счёта |
| `TofStackingAction` | Отсечка поздних оптических фотонов |

**Регистрация фотона.**
- Фотон засчитывается на первом шаге внутри окна SiPM. Значит, он действительно прошёл границу кристалл→окно: отражённые на границе (Френель, ПВО) не считаются. Фотоны, родившиеся в самом окне, тоже не считаются.
- Фотон принимается с вероятностью PDE(λ) × `pdeScale`.
  - PDE(λ) — кривая NUV-SiPM (FBK NUV-HD, Gola et al., Sensors 19 (2019) 308), аппроксимированная по графику: пик 55 % на 420 нм, около 25 % на 300 нм.
  - Есть режим `flat` с постоянной PDE (`/tof/sipm/pde`).
- Время = момент входа в окно + гауссов разброс SPTR. SPTR задаётся как FWHM (`/tof/sipm/sptr`, по умолчанию 70 пс).
- Тип фотона определяется по `GetCreatorProcess()`: `Scintillation` → S, `Cerenkov` → C.

**Взаимодействие гамма-кванта.**
- Для гамма-кванта энерговыделение относится к концу шага (точке взаимодействия), для заряженных частиц — к началу шага.
- В файл пишется время и глубина (DOI, от торца со стороны источника) самого раннего энерговыделения в кристалле.

**Формат CSV.** Файл `tof_output/tof_<материал>_<форма>_z<положение>mm.csv`. Каталог задаётся командой `/tof/output/dir`, суффикс — `/tof/output/tag`.

| Столбцы | Содержание |
|---|---|
| `run, event` | номер прогона и события |
| `material … src_z_mm` | конфигурация прогона (повторяется в каждой строке, чтобы файлы можно было объединять) |
| `module, crystal` | модуль (0: z<0, 1: z>0) и кристалл в матрице (0–3) |
| `edep_keV` | энерговыделение в кристалле |
| `t_gamma_ps, doi_mm` | время и глубина первого взаимодействия (MC-правда) |
| `n_scint, n_cher` | число зарегистрированных фотонов по происхождению |
| `t_first_ps, t_first_scint_ps, t_first_cher_ps` | время первого фотона: любого, сцинтилляционного, черенковского |
| `t01_ps … tNN_ps` | времена первых N фотонов по возрастанию (N = `/tof/output/nFirst`, по умолчанию 10) |
| `types` | происхождение первых N фотонов, например `SCSS…` |

Время отсчитывается от момента аннигиляции (t = 0).

**Отсечка поздних фотонов** (`/tof/opt/timeCut`, 0 — выключена).
- Фотоны, рождённые позже 5 нс, на временную отметку не влияют, но составляют основную часть времени счёта: при τ = 40 нс в первые 5 нс высвечивается 12 % света LYSO, у BGO с τ = 300 нс — 1.7 %.
- Побочный эффект: `n_scint` считает только фотоны, рождённые в первые 5 нс. Для энергетического спектра используется `edep_keV`.

**Зерно генератора.** При `/tof/output/autoSeed true` (по умолчанию) зерно вычисляется из имени выходного файла стабильным хешем (FNV-1a). Каждая конфигурация и положение источника получают свой независимый поток случайных чисел, а повторный запуск даёт тот же результат.

## Проверка и результат

300 событий на материал, параллелепипед 3×3×20 мм, ESR, источник в центре:

| | LYSO | BGO | PbF₂ |
|---|---|---|---|
| Время счёта, мс/событие | 32 | 2.4 | 0.35 |
| Совпадений «1 кристалл + 1 кристалл» на 300 событий | 26 | 22 | 18 |
| `n_scint` в фотопике (> 500 кэВ, первые 5 нс) | 333 | 16 | 0 |
| `n_cher` в фотопике | 0.96 | 2.5 | 1.65 |
| Доля событий, где первый фотон черенковский | 11 % | 68 % | 75 % |
| События фотопика без единого фотона | 0 % | 0 % | 25 % |
| Медиана (t_first − t_gamma), пс | 275 | 465 | 398 |

- Глубина первого взаимодействия распределена от 0 до 20 мм, среднее около 6 мм. Это соответствует длине ослабления 511 кэВ в этих материалах (~1 см).
- Результаты согласуются с литературой по порядку величины: для BGO с NUV-SiPM регистрируется несколько черенковских фотонов на событие, и они чаще всего определяют временную отметку (Kwon et al., PMB 61 (2016) L38; Brunner & Schaart, PMB 62 (2017) 4421).
- Найдена и исправлена ошибка первой версии: время и глубина гамма-взаимодействия брались в начале шага (на входной грани кристалла), из-за чего DOI всегда был 0.
