# 007. README: описание режима tof

**Дата:** 2026-10-07

## Что сделано

В README добавлен раздел о режиме tof:
- установка и физика;
- все команды макроса;
- макросы и примеры запуска, включая параллельный запуск серии;
- время счёта;
- формат выходного CSV;
- запуск анализа.

Обновлены структура репозитория и вводная таблица режимов (`ring` / `tof`).

## Зачем

Чтобы через полгода, на защите или при передаче проекта другому человеку можно было собрать, запустить и проанализировать режим tof без чтения исходников. Отдельно указано, сколько считается один прогон: оптические фотоны делают расчёт дорогим, и это нужно знать до запуска.

## Как

- **Время счёта** в таблице — по замерам серии из шага 006 (Intel Core i5-12450H, 6 процессов параллельно), уже после исправления модели обёртки (шаг 005).
- **Параметры** перечислены по группам команд со ссылкой на `macros/tof/config_default.mac`, где у каждого параметра есть комментарий и значение по умолчанию.

## Проверка и результат

Команды из README выполнены:
- сборка;
- `-m tof tof/test.mac`;
- `run_tof_campaign.py`;
- `analysis/tof/tof_analysis.py`.

Пути и имена файлов совпадают с фактическими.
